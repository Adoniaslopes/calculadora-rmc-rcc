# Calculadora RMC/RCC

Converte o cartão de crédito consignado (RMC/RCC) do INSS em empréstimo consignado comum, à taxa média do Banco Central do mês da contratação (SGS 25468), e apura:

- a data em que a dívida estaria quitada (ou a previsão de quitação);
- os descontos feitos a mais e o indébito atualizado (IPCA/Lei 14.905, SELIC ou INPC + 1%);
- a repetição simples até 30/03/2021 e em dobro a partir de abril/2021 (EAREsp 676.608/STJ);
- a memória de cálculo mês a mês, exportável em Word.

Abra `index.html` no navegador. Índices do Banco Central embutidos até 09/2026.
Envie o PDF do extrato de empréstimos do INSS e, se tiver, o Histórico de Créditos (HISCRE): a leitura é feita no próprio navegador, sem enviar dados a servidores. Confira os dados lidos antes de usar o cálculo.
